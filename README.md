> O website da empresa ION foi desenvolvido para apresentar o projeto **Conserta Já**, divulgar os serviços prestados pela plataforma e conectar prestadores de manutenção especializada (como paneleiros, afiadores e técnicos de eletrodomésticos) a potenciais clientes.

---

## Sobre o Projeto

Este repositório contém o código-fonte do website oficial desenvolvido como parte do Trabalho de Conclusão de Curso (TCC) na ETEC. Ele atua como a página de apresentação do ecossistema Conserta Já, trazendo informações institucionais, explicação sobre os serviços e interface responsiva adaptada a dispositivos móveis e desktops.

---

## Tecnologias Utilizadas

* **HTML5:** Estruturação semântica das páginas web.
* **CSS3:** Estilização, regras visuais, animações e layout responsivo.
* **JavaScript:** Interatividade, comportamentos dinâmicos e manipulação da interface.
