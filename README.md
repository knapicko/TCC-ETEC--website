# ION — Website TCC (ETEC)

> **Projeto de Conclusão de Curso (TCC) desenvolvido para o curso técnico na ETEC.**
> 
> O **ION** é uma plataforma/website desenvolvida para apresentar a empresa fictícia/projeto **ION**, reunindo informações institucionais, serviços e interface responsiva para usuários.

---

## Sobre o Projeto

Este repositório contém o código-fonte do website oficial desenvolvido como parte do Trabalho de Conclusão de Curso (TCC). O objetivo principal do projeto é aplicar os conceitos e práticas aprendidos ao longo do curso técnico da ETEC em desenvolvimento web front-end, utilizando o website para divulgação e apresentação do projeto principal.

---

## Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:

* **HTML5:** Estruturação semântica das páginas web.
* **CSS3:** Estilização, layout e responsividade.
* **JavaScript:** Interatividade, animações e comportamentos dinâmicos na interface.
